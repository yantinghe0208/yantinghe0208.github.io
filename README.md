# Yanting He — Academic Website

Personal academic website for Yanting He, Assistant Professor of Marketing at
The Chinese University of Hong Kong, Shenzhen.

The site is generated as static HTML and published automatically through
GitHub Pages whenever the `main` branch is updated.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The GitHub Pages artifact is generated in `dist/client`.
